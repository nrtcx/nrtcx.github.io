배당 변환기: 6가지 배당 표기 변환 공식

계산 가이드 · 최종 수정 2026-10-13

같은 배당이 지역에 따라 2.50, +150, 3/2, 1.50, −0.667 로 적힙니다. 전부 소수 배당 하나로 바꿔서 읽으면 헷갈릴 일이 없습니다. 변환 공식과 표를 한곳에 모았습니다.

기준은 소수 배당

소수 배당은 금액 1 을 넣었을 때 원금을 포함해 돌려받는 총액입니다. 2.50 이면 1 을 넣어 2.50 을 받고 순이익은 1.50 입니다. 다른 표기는 대부분 이 순이익 부분(소수 배당 − 1)을 다른 방식으로 적은 것입니다. 아래에서 d 는 소수 배당입니다.

표기별 변환 공식

홍콩d − 1HK + 1

인도네시아 (d < 2)−1 ÷ (d − 1)음수 I: 1/|I| + 1
말레이 (d ≤ 2)+(d − 1)양수 M: M + 1
말레이 (d > 2)−1 ÷ (d − 1)음수 M: 1/|M| + 1

미국식과 인도네시아식은 단위만 다르고 구조가 같습니다. 미국식을 100 으로 나누면 인도네시아식입니다. 말레이식은 부호 규칙이 반대라서, 양수가 정배당(강팀) 쪽이고 음수가 역배당 쪽입니다.

직접 돌려 보기

아무 표기에나 값을 넣으면 나머지가 모두 채워집니다. 소수 배당 2.50 을 넣어 두었습니다.

배당 변환기 전체 화면으로 열기

배당 변환기 (소수·미국·분수) - 놀이터

암시 확률

암시 확률 = 1 / d

소수 배당의 역수가 그 배당이 암시하는 확률입니다. 2.50 이면 40% 입니다. 한 경기 모든 결과의 암시 확률을 더하면 100% 를 넘는데, 넘는 부분이 배당표의 마진입니다. 그래서 암시 확률은 실제 확률보다 항상 조금 높게 나옵니다.

헷갈리기 쉬운 부분

  • 분수 배당은 순이익 비율입니다. 3/2 는 2 를 넣어 3 을 번다는 뜻이고 원금은 따로 돌아옵니다. 소수로는 2.50 이지 1.50 이 아닙니다.
  • 미국식 음수는 필요한 금액입니다. −200 은 100 을 벌기 위해 200 을 넣어야 한다는 뜻입니다.
  • 말레이 음수는 손실 기준입니다. −0.50 은 1 을 벌려면 0.50 을 위험에 건다는 뜻으로, 소수 배당 3.00 입니다.
  • 홍콩 배당 1.00 과 소수 배당 2.00 은 같은 값입니다. 원금 포함 여부만 다릅니다.

코드로 옮기면

const toDecimal = {
  american: (a) => (a > 0 ? a / 100 + 1 : 100 / Math.abs(a) + 1),
  fractional: (num, den) => num / den + 1,
  hongkong: (h) => h + 1,
  indonesian: (i) => (i > 0 ? i + 1 : 1 / Math.abs(i) + 1),
  malay: (m) => (m > 0 ? m + 1 : 1 / Math.abs(m) + 1),
};

const fromDecimal = (d) => ({
  american: d >= 2 ? (d - 1) * 100 : -100 / (d - 1),
  hongkong: d - 1,
  indonesian: d >= 2 ? d - 1 : -1 / (d - 1),
  malay: d <= 2 ? d - 1 : -1 / (d - 1),
  impliedProb: 1 / d,
});

fromDecimal(2.5);
// american 150, hongkong 1.5, indonesian 1.5, malay -0.667, impliedProb 0.4

자주 묻는 질문

국내에서 쓰는 배당은 어떤 표기인가요?
소수 배당입니다. 유럽식이라고도 부릅니다. 원금을 포함한 총 수령 배수라서 금액에 곱하기만 하면 수령액이 나옵니다.
미국식 −110 은 왜 그렇게 자주 보이나요?
양쪽 확률이 반반인 마켓에 마진을 얹은 표준 가격이기 때문입니다. 소수로 1.91 이고, 양쪽이 모두 −110 이면 배당표 마진은 약 4.8% 입니다.
분수 배당 5/2 와 2/5 는 어떻게 다른가요?
5/2 는 2 를 넣어 5 를 버는 역배당으로 소수 3.50 입니다. 2/5 는 5 를 넣어 2 를 버는 정배당으로 소수 1.40 입니다. 앞 숫자가 크면 역배당입니다.

다른 가이드

  • 양방(아비트리지) 계산배당 역수의 합으로 차익 여부를 판정하고 금액을 나누는 법
  • 폴더 조합 배당 계산총 배당은 곱셈, 그런데 환급률도 같이 곱해진다는 점
  • 북 마진과 노빅 계산배당표에서 마진을 뽑고 공정 배당으로 되돌리는 법
  • 켈리 비율 계산우위가 있을 때 자금의 몇 % 인지, 그리고 왜 절반만 쓰는지
  • 해지(헤지)와 중간 정산 계산남은 한 경기의 반대편에 얼마를 넣어야 손익이 고정되는지
  • 배당 흐름 보는 법초기 배당과 현재 배당의 차이를 확률로 바꿔 읽는 방법
  • 해외 배당 보는 법과 배당 비교같은 경기의 배당이 곳마다 다른 이유와 비교하는 순서
  • 프로토 배당률 계산법승부식 예상 적중금 계산과 연장전, 적중 특례 규칙
  • 역배당 뜻과 무승부 확률정배당과 역배당, 축구 무승부 비율, 이변을 숫자로 재는 법

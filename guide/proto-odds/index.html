프로토 배당률 계산법: 승부식 예상 적중금

데이터 읽는 법 · 최종 수정 2026-10-13

프로토 승부식의 계산은 고른 경기의 배당률을 모두 곱하는 것이 전부입니다. 헷갈리는 부분은 계산이 아니라 규칙입니다. 연장전을 포함하는지, 경기가 취소되면 어떻게 되는지를 함께 정리했습니다.

예상 적중금 계산

조합 배당률 = 선택한 경기 배당률의 곱
예상 적중금 = 구매 금액 × 조합 배당률

배당률 1.85, 2.10, 1.50 세 경기를 골라 1만 원을 구매하면 조합 배당률은 1.85 × 2.10 × 1.50 = 5.83 이고 예상 적중금은 약 58,300원입니다. 프로토 승부식은 발매 시점에 정해진 배당률이 그대로 적용되는 고정 배당률 방식이라, 구매 후에 배당률이 바뀌어도 내 조합에는 영향이 없습니다.

직접 돌려 보기

위 예제 값을 넣어 둔 계산기입니다. 경기 수와 배당률을 바꿔 가며 확인해 보세요.

조합(폴더) 배당 계산기 - 놀이터

배당률이 암시하는 확률과 환급률

배당률의 역수는 그 결과의 암시 확률입니다. 한 경기의 승, 무, 패 배당률 역수를 모두 더하면 1 보다 큰 값이 나오고, 그 역수가 그 경기의 환급률입니다.

환급률 = 1 ÷ (1/승 + 1/무 + 1/패)

예를 들어 승 1.95, 무 3.15, 패 3.25 라면 역수 합은 0.5128 + 0.3175 + 0.3077 = 1.1380 이고 환급률은 87.9% 입니다. 조합으로 묶으면 이 환급률이 경기 수만큼 곱해집니다. 두 경기면 약 77%, 세 경기면 약 68% 입니다. 경기 수를 늘릴수록 배당률은 커지지만 조건은 그만큼 불리해진다는 점을 숫자로 알아 둘 필요가 있습니다.

회차별 대상 경기의 배당률과 환급률은 놀이터 프로토 회차 리포트에서 볼 수 있습니다.

자주 헷갈리는 규칙

연장전 포함 여부

종목기준
축구전후반 정규 시간과 추가 시간까지. 연장전과 승부차기는 포함하지 않습니다.
야구연장전을 포함한 최종 결과.
농구연장전을 포함한 최종 결과.

토너먼트 축구 경기에서 90분이 무승부로 끝나고 연장에서 승부가 났다면 승부식 결과는 무승부입니다. 세부 기준은 유형과 회차에 따라 다를 수 있으므로 구매 전 공식 발매 안내를 확인해야 합니다.

적중 특례

대상 경기가 취소되거나 정해진 기간 안에 열리지 않으면 그 경기는 결과와 관계없이 적중으로 처리하고 배당률을 1.0 으로 적용합니다. 세 경기 조합에서 한 경기가 특례가 되면 나머지 두 경기 배당률만 곱해집니다. 위 예제에서 둘째 경기가 특례라면 1.85 × 1.0 × 1.50 = 2.78 입니다.

핸디캡과 언더오버

핸디캡 유형은 홈 팀 점수에 기준 점수를 더하거나 뺀 뒤 승무패를 가립니다. 언더오버 유형은 양 팀 합계 점수가 기준 값보다 큰지 작은지입니다. 같은 경기라도 유형이 다르면 별개의 대상 경기로 취급됩니다.

알아 둘 것

프로토는 체육진흥투표권으로, 만 19세 이상만 공식 판매점과 공식 온라인 발매 사이트에서 구매할 수 있습니다. 구매 한도와 적중금 과세 기준은 법령과 공식 안내에 정해져 있으며 바뀔 수 있으므로, 금액이 큰 경우에는 공식 안내를 직접 확인하는 것이 정확합니다.

코드로 옮기면

function protoPayout(odds, amount, voided = []) {
  // voided: 적중 특례가 된 경기의 순번
  const total = odds.reduce((acc, o, i) => acc * (voided.includes(i) ? 1.0 : o), 1);
  return { totalOdds: total, payout: amount * total };
}

protoPayout([1.85, 2.10, 1.50], 10000);        // totalOdds 5.8275, payout 58275
protoPayout([1.85, 2.10, 1.50], 10000, [1]);   // totalOdds 2.775,  payout 27750

자주 묻는 질문

구매 후 배당률이 바뀌면 적중금도 바뀌나요?
바뀌지 않습니다. 승부식은 구매 시점의 배당률이 확정 적용됩니다. 발매 중에 배당률이 조정되어도 이미 구매한 조합에는 영향이 없습니다.
축구 경기가 연장전에서 끝났습니다. 결과는 어떻게 되나요?
축구는 정규 시간 기준이므로 90분과 추가 시간까지의 점수로 판정합니다. 연장전이나 승부차기에서 갈린 승패는 반영되지 않습니다.
조합 배당률 표기가 계산값과 조금 다릅니다.
곱한 값을 표기할 때 소수 자릿수를 정리하는 규칙 때문입니다. 실제 적중금은 공식 발매 화면에 표시된 값이 기준입니다.

다른 가이드

  • 양방(아비트리지) 계산배당 역수의 합으로 차익 여부를 판정하고 금액을 나누는 법
  • 폴더 조합 배당 계산총 배당은 곱셈, 그런데 환급률도 같이 곱해진다는 점
  • 북 마진과 노빅 계산배당표에서 마진을 뽑고 공정 배당으로 되돌리는 법
  • 켈리 비율 계산우위가 있을 때 자금의 몇 % 인지, 그리고 왜 절반만 쓰는지
  • 배당 변환소수, 미국식, 분수, 홍콩, 인도네시아, 말레이 표기 한 번에
  • 해지(헤지)와 중간 정산 계산남은 한 경기의 반대편에 얼마를 넣어야 손익이 고정되는지
  • 배당 흐름 보는 법초기 배당과 현재 배당의 차이를 확률로 바꿔 읽는 방법
  • 해외 배당 보는 법과 배당 비교같은 경기의 배당이 곳마다 다른 이유와 비교하는 순서
  • 역배당 뜻과 무승부 확률정배당과 역배당, 축구 무승부 비율, 이변을 숫자로 재는 법
  • 스포츠 분석 사이트 숫자 읽는 법시장 확률, 최근 폼, 상대 전적, 결장을 어떤 순서로 읽는지

계산 결과는 입력한 값이 그대로 유지된다는 가정 위의 참고용 수치이며, 어떤 베팅도 권유하지 않습니다. 과몰입이 걱정되면 한국도박문제예방치유원 상담전화 1336 을 이용해 주세요.

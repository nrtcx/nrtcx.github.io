축구 배당 흐름 보는 법: 변동을 확률로 읽기

데이터 읽는 법 · 최종 수정 2026-10-13

배당 흐름은 처음 나온 배당과 지금 배당 사이의 차이입니다. 숫자가 내려갔다는 사실보다 중요한 것은 그 변화가 확률로 몇 %p 인지, 그리고 왜 움직였는지입니다. 읽는 순서를 정리했습니다.

먼저 용어

  • 초기 배당: 경기가 처음 등록됐을 때의 배당입니다. 보통 경기 며칠 전에 나옵니다.
  • 현재 배당: 지금 시점의 배당입니다. 경기 시작 직전의 값은 마감 배당이라고 부릅니다.
  • 배당 하락: 배당이 내려갔다는 것은 그 결과가 나올 확률을 시장이 더 높게 보게 됐다는 뜻입니다. 영어권에서는 드로핑 오즈(dropping odds)라고 합니다.
  • 배당 상승: 반대로 그 결과의 평가가 낮아졌다는 뜻입니다. 한쪽이 내려가면 나머지 결과는 올라갑니다.

1단계: 변동률

변동률 = (현재 배당 − 초기 배당) ÷ 초기 배당

홈 승 배당이 2.10 에서 1.90 으로 내려갔다면 (1.90 − 2.10) ÷ 2.10 = −9.5% 입니다. 변동률은 순위를 매기기에는 편하지만 배당 크기에 따라 의미가 달라집니다. 1.30 에서 1.20 으로 가는 것과 5.00 에서 4.60 으로 가는 것은 변동률이 비슷해도 확률 변화는 전혀 다릅니다.

2단계: 확률 변화로 바꾸기

배당의 역수가 암시 확률입니다. 2.10 은 47.6%, 1.90 은 52.6% 이므로 5.0%p 올랐습니다. 다만 이 값에는 배당표의 마진이 섞여 있습니다. 세 결과를 모두 놓고 마진을 걷어낸 공정 확률로 비교해야 정확합니다.

결과초기 배당현재 배당초기 공정 확률현재 공정 확률변화
홈 승2.101.9045.4%50.1%+4.7%p
무승부3.403.5028.1%27.2%−0.9%p
원정 승3.604.2026.5%22.7%−3.8%p

이 표를 보면 홈 승 평가가 4.7%p 올랐고, 그 대부분이 원정 승에서 빠졌다는 것을 알 수 있습니다. 무승부는 거의 그대로입니다. 한 줄의 변동률만 볼 때는 보이지 않던 내용입니다.

오늘 경기의 실제 변동은 놀이터 축구 배당 흐름 표에서 볼 수 있습니다.

배당이 움직이는 네 가지 이유

  • 새 정보: 선발 명단, 부상, 징계, 감독 교체, 날씨 같은 소식이 반영됩니다. 명단 발표 직후에 움직임이 몰리는 이유입니다.
  • 자금 쏠림: 한쪽으로 참여가 몰리면 위험을 줄이기 위해 그쪽 배당을 내립니다. 인기 팀 경기에서 자주 나타나고, 실제 전력 변화와 무관할 수 있습니다.
  • 시장 간 정렬: 다른 곳과 배당 차이가 벌어지면 따라 맞춥니다. 한 곳이 먼저 움직이고 나머지가 뒤따르는 형태로 보입니다.
  • 마진 조정: 경기 시작이 가까워지면 초기에 넉넉히 잡았던 마진을 줄이면서 모든 결과의 배당이 조금씩 오르기도 합니다. 이것은 확률 평가의 변화가 아닙니다.

해석할 때 흔한 실수

  • 작은 변동에 의미를 두는 것: 1~2% 수준의 변동은 일상적인 미세 조정입니다. 확률로 1%p 가 안 되는 변화는 신호로 보기 어렵습니다.
  • 한 곳의 배당만 보는 것: 한 곳에서만 움직였다면 그곳의 사정일 가능성이 큽니다. 여러 곳이 같은 방향으로 움직였는지 확인해야 합니다.
  • 거래가 적은 리그를 같은 기준으로 보는 것: 하위 리그는 적은 금액으로도 배당이 크게 움직입니다. 같은 10% 하락이라도 무게가 다릅니다.
  • 하락을 결과 예고로 받아들이는 것: 배당이 내려간 쪽이 이긴다는 뜻이 아닙니다. 평가가 45% 에서 50% 로 올랐다면 여전히 절반은 다른 결과가 나옵니다.

코드로 옮기면

function fairProbs(odds) {
  const s = odds.reduce((sum, o) => sum + 1 / o, 0);
  return odds.map((o) => 1 / o / s);
}

function movement(open, current) {
  const before = fairProbs(open);
  const after = fairProbs(current);
  return open.map((o, i) => ({
    changePct: (current[i] - o) / o,          // 변동률
    probShift: after[i] - before[i],          // 공정 확률 변화
  }));
}

movement([2.10, 3.40, 3.60], [1.90, 3.50, 4.20]);
// 홈 승 changePct -0.095, probShift +0.047

자주 묻는 질문

배당 흐름은 언제 보는 것이 좋나요?
선발 명단이 나오는 경기 시작 약 1시간 전과 그 직후의 변화가 정보가 가장 많이 담기는 구간입니다. 며칠 전의 초기 배당과 비교하면 그사이 평가가 어떻게 바뀌었는지 한눈에 보입니다.
배당이 급락한 경기는 그쪽이 이길 가능성이 높은가요?
평가가 올랐다는 뜻일 뿐 결과를 알려 주지는 않습니다. 급락 후의 배당에는 이미 그 평가가 반영되어 있으므로, 급락했다는 사실만으로 유리해지지는 않습니다.
모든 결과의 배당이 같이 오르는 경우도 있나요?
있습니다. 마진을 줄인 경우입니다. 이때는 공정 확률로 바꿔 보면 거의 변화가 없습니다. 변동률만 보면 놓치는 부분입니다.

다른 가이드

  • 양방(아비트리지) 계산배당 역수의 합으로 차익 여부를 판정하고 금액을 나누는 법
  • 폴더 조합 배당 계산총 배당은 곱셈, 그런데 환급률도 같이 곱해진다는 점
  • 북 마진과 노빅 계산배당표에서 마진을 뽑고 공정 배당으로 되돌리는 법
  • 켈리 비율 계산우위가 있을 때 자금의 몇 % 인지, 그리고 왜 절반만 쓰는지
  • 배당 변환소수, 미국식, 분수, 홍콩, 인도네시아, 말레이 표기 한 번에
  • 해지(헤지)와 중간 정산 계산남은 한 경기의 반대편에 얼마를 넣어야 손익이 고정되는지
  • 해외 배당 보는 법과 배당 비교같은 경기의 배당이 곳마다 다른 이유와 비교하는 순서
  • 프로토 배당률 계산법승부식 예상 적중금 계산과 연장전, 적중 특례 규칙
  • 역배당 뜻과 무승부 확률정배당과 역배당, 축구 무승부 비율, 이변을 숫자로 재는 법

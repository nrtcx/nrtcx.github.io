해지(헤지) 중간 정산 계산기: 헤지 금액과 확정 손익

계산 가이드 · 최종 수정 2026-10-13

hedge 를 소리 나는 대로 해지라고도 적습니다. 이미 넣어 둔 선택이 아직 진행 중일 때, 반대편에 얼마를 넣으면 결과와 상관없이 손익이 같아지는지 구하는 계산입니다. 공식은 나눗셈 한 번입니다.

공식

헤지 금액 = (원 금액 × 원 배당) ÷ 반대편 배당
확정 손익 = 원 금액 × 원 배당 − 원 금액 − 헤지 금액

원래 선택이 맞았을 때 받을 금액과, 반대편이 맞았을 때 받을 금액을 같게 맞추는 것이 전부입니다. 양쪽 수령액이 같아지면 어느 쪽이 나와도 손익이 같습니다.

예제 1: 조합의 마지막 한 경기

1만 원으로 넣은 3폴더(총 배당 5.83) 중 두 경기가 맞고 마지막 한 경기가 남았습니다. 그 경기 반대편 배당이 2.00 이라면 다음과 같습니다.

항목계산값
원 선택 적중 시 수령10,000 × 5.8358,300원
헤지 금액58,300 ÷ 2.0029,150원
총 투입10,000 + 29,15039,150원
어느 쪽이든 수령58,300원
확정 손익58,300 − 39,150+19,150원

헤지를 하지 않으면 +48,300원 아니면 −10,000원입니다. 헤지를 하면 어느 쪽이든 +19,150원입니다. 기대값을 조금 내주고 결과의 편차를 0 으로 만드는 교환입니다.

예제 2: 손실을 줄이는 헤지

10만 원을 배당 2.00 에 넣었는데 상황이 불리해져 반대편 배당이 1.60 으로 내려갔습니다. 헤지 금액은 200,000 ÷ 1.60 = 125,000원이고, 확정 손익은 200,000 − 100,000 − 125,000 = −25,000원입니다. 이익이 나는 헤지가 아니라 최대 손실을 10만 원에서 2만 5천 원으로 줄이는 헤지입니다.

예제 1 의 값을 넣어 둔 계산기입니다. 반대편 배당을 바꿔 가며 확정 손익이 어떻게 변하는지 확인해 보세요.

헤지(해지)·중간정산 계산기 - 놀이터

언제 이익이 확정되나

확정 손익이 양수가 되는 조건은 식을 정리하면 한 줄입니다.

1/원 배당 + 1/반대편 배당 < 1

양방 계산의 판정식과 같습니다. 헤지는 시간 차를 두고 완성하는 양방이라고 볼 수 있습니다. 처음 넣을 때는 반대편 배당이 낮아서 조건이 안 맞지만, 조합의 앞 경기들이 맞거나 경기 흐름이 유리해지면 원 배당이 사실상 높아진 셈이 되어 조건이 충족됩니다.

전부 고정하지 않는 선택

헤지 금액은 0 과 완전 헤지 금액 사이에서 고를 수 있습니다.

  • 원금만 지키기: 반대편이 나와도 본전이 되는 금액만 넣습니다. 헤지 금액 = 원 금액 ÷ (반대편 배당 − 1). 예제 1 이라면 10,000원이고, 원 선택이 맞으면 +38,300원, 반대편이 맞으면 0원입니다.
  • 완전 헤지: 위 공식 그대로 양쪽 손익을 같게 만듭니다.
  • 헤지 안 함: 기대값이 가장 높지만 편차도 가장 큽니다.

어느 것이 옳은지는 계산이 아니라 그 결과가 자금에서 차지하는 비중에 달려 있습니다. 반대편 배당에도 마진이 들어 있으므로 헤지를 할수록 기대값은 조금씩 줄어든다는 점은 기억해야 합니다.

코드로 옮기면

function hedge(stake, odds, oppositeOdds) {
  const payout = stake * odds;
  const hedgeStake = payout / oppositeOdds;
  return {
    hedgeStake,
    lockedProfit: payout - stake - hedgeStake,
    breakEvenHedge: stake / (oppositeOdds - 1),   // 원금만 지키는 금액
  };
}

hedge(10000, 5.83, 2.0);
// hedgeStake 29150, lockedProfit 19150, breakEvenHedge 10000

자주 묻는 질문

해지 계산기와 헤지 계산기는 다른 건가요?
같은 계산입니다. 영어 hedge 를 해지로 적는 경우가 많아 두 이름이 함께 쓰입니다. 계약을 취소한다는 뜻의 해지와는 관계가 없습니다.
중간 정산(캐시아웃) 제안과 직접 헤지 중 무엇이 낫나요?
제안 금액에서 원 금액을 뺀 값을 직접 헤지했을 때의 확정 손익과 비교하면 됩니다. 중간 정산 제안에는 별도 마진이 붙는 경우가 많아 직접 계산한 값보다 낮게 나오는 편입니다.
반대편이 둘 이상이면 어떻게 하나요?
무승부가 있는 경기라면 남은 결과 각각에 대해 수령액이 같아지도록 금액을 나눕니다. 각 결과에 (원 수령액 ÷ 그 결과 배당) 만큼 넣으면 됩니다.

다른 계산 가이드

  • 양방(아비트리지) 계산배당 역수의 합으로 차익 여부를 판정하고 금액을 나누는 법
  • 폴더 조합 배당 계산총 배당은 곱셈, 그런데 환급률도 같이 곱해진다는 점
  • 북 마진과 노빅 계산배당표에서 마진을 뽑고 공정 배당으로 되돌리는 법
  • 켈리 비율 계산우위가 있을 때 자금의 몇 % 인지, 그리고 왜 절반만 쓰는지
  • 배당 변환소수, 미국식, 분수, 홍콩, 인도네시아, 말레이 표기 한 번에

계산 결과는 입력한 값이 그대로 유지된다는 가정 위의 참고용 수치이며, 어떤 베팅도 권유하지 않습니다. 과몰입이 걱정되면 한국도박문제예방치유원 상담전화 1336 을 이용해 주세요.

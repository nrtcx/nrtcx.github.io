스포츠 픽 사이트 적중률 검증하는 법

데이터 읽는 법 · 최종 수정 2026-10-15

적중률 80% 라는 숫자만으로는 아무것도 알 수 없습니다. 몇 개 중 몇 개인지, 평균 배당이 얼마였는지가 빠져 있기 때문입니다. 스포츠 픽 사이트에서 전적을 볼 때 직접 해 볼 수 있는 계산 네 가지를 정리했습니다.

1. 표본: 몇 개 중 몇 개인가

픽 5개 중 4개를 맞히면 80% 입니다. 하지만 실력이 50% 인 사람도 5개 중 4개 이상을 맞힐 확률이 19% 가까이 됩니다. 표본이 작으면 적중률은 실력을 말해 주지 못합니다.

표본을 반영하는 간단한 방법은 신뢰 하한을 구하는 것입니다. "이 사람의 실제 적중률이 적어도 이 정도는 된다"고 95% 수준으로 말할 수 있는 값입니다.

전적적중률신뢰 하한 (95%)
5개 중 4개80.0%37.6%
20개 중 14개70.0%48.1%
200개 중 120개60.0%53.1%

겉으로는 80% 가 가장 높지만 하한으로 보면 200개 중 120개를 맞힌 쪽이 가장 믿을 만합니다. 전적을 볼 때 픽 개수가 함께 표시되지 않는 사이트라면 적중률 숫자는 건너뛰는 편이 낫습니다.

2. 손익분기 적중률: 평균 배당과 같이 보기

손익분기 적중률 = 1 ÷ 평균 배당
평균 배당손익분기 적중률
1.3076.9%
1.6062.5%
1.9052.6%
2.5040.0%

평균 배당 1.30 으로 적중률 75% 를 기록했다면 손익분기 76.9% 에 못 미칩니다. 반대로 평균 배당 2.50 으로 45% 를 맞혔다면 손익분기 40% 를 넘습니다. 적중률은 평균 배당 없이는 높은지 낮은지 판단할 수 없습니다.

3. 수익률: 1픽을 1유닛으로

수익률 = (적중 픽의 배당 합계 − 전체 픽 수) ÷ 전체 픽 수

픽 100개 중 55개를 평균 배당 1.90 으로 맞혔다면 돌려받는 합계는 55 × 1.90 = 104.5 이고, 수익률은 (104.5 − 100) ÷ 100 = +4.5% 입니다. 모든 픽을 같은 크기로 계산해야 "큰 금액을 건 한 번"으로 성적이 부풀려지지 않습니다.

4. 마감 배당 대비 우위

결과는 운의 영향을 크게 받습니다. 운을 덜 타는 지표가 마감 배당 대비 우위입니다. 픽을 올린 시점의 배당이 경기 직전의 마감 배당보다 높았는지를 봅니다.

우위 = 픽 등록 시 배당 ÷ 마감 배당 − 1

2.00 에 올린 픽의 마감 배당이 1.90 이었다면 2.00 ÷ 1.90 − 1 = +5.3% 입니다. 시장이 나중에 같은 방향으로 움직였다는 뜻이므로, 결과와 상관없이 판단이 시장보다 빨랐다고 볼 수 있습니다. 이 값이 꾸준히 양수인 사람은 표본이 쌓일수록 수익률도 따라오는 경향이 있습니다.

전적을 볼 때의 점검표

  • 픽 수가 표시되는가. 표본을 알 수 없는 적중률은 의미가 없습니다.
  • 적중 판정이 자동인가. 작성자가 결과를 직접 적는 구조라면 숫자를 믿을 근거가 없습니다.
  • 빠진 픽이 없는가. 잘 맞은 픽만 공개하고 나머지를 숨길 수 있는 구조인지 확인합니다.
  • 수익률이 같은 크기 기준인가. 픽마다 금액을 다르게 잡은 수익률은 비교가 되지 않습니다.

놀이터 스포츠 픽 사이트에서는 픽마다 작성자의 누적 전적이 함께 표시되고, 픽스터 랭킹에서 위 네 가지 숫자를 한 표로 볼 수 있습니다.

국내 스포츠픽 사이트 가운데 전적을 캡처 이미지로만 보여 주는 곳은 위 계산을 해 볼 수 없습니다. 원본 기록이 표로 공개돼 있는지가 첫 번째 기준입니다.

코드로 옮기면

// 적중률의 95% 신뢰 하한 (윌슨 구간)
function lowerBound(hits, n, z = 1.96) {
  const p = hits / n;
  const a = p + (z * z) / (2 * n);
  const b = z * Math.sqrt((p * (1 - p)) / n + (z * z) / (4 * n * n));
  return (a - b) / (1 + (z * z) / n);
}

// 1픽 = 1유닛 수익률. picks: [{ odds, hit }]
function roi(picks) {
  const back = picks.reduce((s, p) => s + (p.hit ? p.odds : 0), 0);
  return (back - picks.length) / picks.length;
}

const closingEdge = (taken, closing) => taken / closing - 1;

lowerBound(4, 5);      // 0.376
lowerBound(120, 200);  // 0.531
closingEdge(2.0, 1.9); // 0.053

자주 묻는 질문

픽이 몇 개쯤 쌓여야 적중률을 믿을 수 있나요?
정해진 기준은 없지만 100개 아래에서는 운의 비중이 큽니다. 개수보다 신뢰 하한을 보는 편이 정확합니다. 하한이 손익분기 적중률을 넘는지 확인하시기 바랍니다.
적중률이 높은데 수익률이 마이너스일 수 있나요?
있습니다. 평균 배당이 낮으면 그렇습니다. 평균 배당 1.30 에서는 적중률이 76.9% 를 넘어야 수익률이 0 이상이 됩니다.
유료픽은 무엇을 보고 골라야 하나요?
판매자의 픽 수, 수익률, 마감 배당 대비 우위를 먼저 보고, 미적중일 때 환불되는 구조인지 확인하시기 바랍니다. 픽은 예측이며 결과를 보장하지 않습니다.

다른 가이드

  • 양방(아비트리지) 계산배당 역수의 합으로 차익 여부를 판정하고 금액을 나누는 법
  • 폴더 조합 배당 계산총 배당은 곱셈, 그런데 환급률도 같이 곱해진다는 점
  • 북 마진과 노빅 계산배당표에서 마진을 뽑고 공정 배당으로 되돌리는 법
  • 켈리 비율 계산우위가 있을 때 자금의 몇 % 인지, 그리고 왜 절반만 쓰는지
  • 배당 변환소수, 미국식, 분수, 홍콩, 인도네시아, 말레이 표기 한 번에
  • 해지(헤지)와 중간 정산 계산남은 한 경기의 반대편에 얼마를 넣어야 손익이 고정되는지
  • 배당 흐름 보는 법초기 배당과 현재 배당의 차이를 확률로 바꿔 읽는 방법
  • 해외 배당 보는 법과 배당 비교같은 경기의 배당이 곳마다 다른 이유와 비교하는 순서
  • 프로토 배당률 계산법승부식 예상 적중금 계산과 연장전, 적중 특례 규칙
  • 역배당 뜻과 무승부 확률정배당과 역배당, 축구 무승부 비율, 이변을 숫자로 재는 법
  • 스포츠 분석 사이트 숫자 읽는 법시장 확률, 최근 폼, 상대 전적, 결장을 어떤 순서로 읽는지
